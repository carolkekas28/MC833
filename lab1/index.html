Sobre o projeto

Este projeto consiste na implementação de um servidor Web em Python, utilizando sockets TCP para receber e processar requisições HTTP GET. O servidor identifica o arquivo solicitado pelo navegador, procura esse arquivo em seu diretório local e envia uma resposta HTTP ao cliente.

Quando o arquivo solicitado é encontrado, o servidor retorna a resposta 200 OK juntamente com seu conteúdo. Caso o arquivo não exista, é enviada uma resposta 404 Not Found. O servidor também utiliza threads para permitir o atendimento de múltiplos clientes simultaneamente.

Para demonstrar o funcionamento do servidor, foram utilizadas imagens de três montanhas mundialmente conhecidas: K2, Annapurna e Machapuchare.
